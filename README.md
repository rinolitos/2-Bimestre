# 🚀 Repositório de Projetos — RinoFarma & RinoTalk

Este repositório reúne dois projetos principais desenvolvidos para fins escolares e de prática de desenvolvimento web e banco de dados:

- 💊 **RinoFarma** — Sistema de farmácia com PHP e banco de dados SQL
- 💬 **RinoTalk** — Plataforma de comunicação e site planejado com conceito Mobile First

---

## 🎯 Objetivo Geral

O objetivo deste repositório é organizar dois sistemas diferentes em um único ambiente de desenvolvimento, permitindo:

- Prática de programação web
- Organização de projetos reais
- Aprendizado de banco de dados
- Planejamento de interfaces modernas

---

## 🧠 Tecnologias utilizadas

- PHP
- MySQL / SQL Server
- HTML, CSS e JavaScript
- Git e GitHub

---

## 📌 Projetos

### 💊 RinoFarma
Sistema de farmácia com foco em controle de produtos, clientes e vendas.

### 💬 RinoTalk
Site/plataforma de comunicação e aprendizado de línguas com planejamento Mobile First e identidade visual própria.
