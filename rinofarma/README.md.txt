# 💊 RinoFarma — Sistema de Farmácia

O **RinoFarma** é um sistema de gerenciamento de farmácia desenvolvido com PHP e banco de dados SQL.

---

## 🎯 Objetivo

O sistema tem como objetivo:

- Controlar produtos da farmácia
- Gerenciar clientes
- Organizar vendas
- Facilitar o controle de estoque

---

## ⚙️ Funcionalidades

- Cadastro de produtos
- Atualizações de produtos
- Cadastro de clientes
- Controle de estoque
- Conexão com banco de dados

---

## 🗄️ Banco de Dados

O sistema utiliza um banco de dados relacional com tabelas para:

- Produtos
- Clientes
- Itens de venda

---

## 🧠 Tecnologias utilizadas

- PHP
- SQL (MySQL / SQL Server)
- HTML
- CSS
