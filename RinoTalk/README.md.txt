# 💬 RinoTalk — Planejamento de Site

O **RinoTalk** é um projeto de planejamento de um site moderno focado em comunicação e interação entre usuários.

O projeto segue o conceito **Mobile First**, priorizando a experiência em dispositivos móveis.

---

## 🎯 Objetivo

- Criar uma plataforma de comunicação simples e intuitiva
- Facilitar interação entre usuários
- Organizar conteúdos de forma acessível
- Priorizar experiência mobile

---

## 👥 Público-Alvo

- Adolescentes e jovens (13 a 25 anos)
- Usuários de smartphones
- Pessoas que buscam aprender idiomas de forma rápida e simples

---

## 📱 Mobile First

O projeto é desenvolvido primeiro para celular e depois adaptado para desktop.

### 📌 Justificativas:
- Maioria dos usuários usa celular
- Melhor experiência inicial

### 📌 Adaptações:
- Layout responsivo
- Menu simples
- Textos curtos
- Interface leve

---

## 🎨 Identidade Visual

- Nome: RinoTalk
- Cores:Verde escuro, Verde claro, branco e cinza
- Estilo: moderno e minimalista
- Tipografia: Roboto / Open Sans
